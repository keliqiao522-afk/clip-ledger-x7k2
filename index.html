📋 粘贴导入台词

把整段口播文案直接粘进来（不用手动换行），会自动按 句号 。 / 问号 ？ / 感叹号 ！ / 分号 ； 拆成一行一句台词，追加到当前这条文案的表格里，原有台词不会覆盖。

提示：逗号 ， 不拆句；换行也按一句处理

📋 粘贴导入每日计划

从飞书 / Excel / 表格里直接复制整张表粘进来，一行一天。列顺序照抄截图即可：日期 → 星期 → 场地 → 拍摄明细 → 当日拍摄 → 当日剪辑任务（只有"星期 → 日期"换个顺序也能认）。表头那行会自动跳过。

只覆盖导入的那些天，其他日子原有内容保留
